description: Guided step-by-step walkthrough of a CCAR-F task statement
argument-hint: task statement id, e.g. 1.1 (empty = recommend next)
---
Enter TEACH mode (see CLAUDE.md) for task statement: $ARGUMENTS

1. Read CURRICULUM.md and find this task statement's Guided exercise. Read
   PROGRESS.md for prior attempts or weak areas (create it from
   PROGRESS.template.md if missing).
2. Brief the learner in 3–4 sentences: what they'll build and why the exam
   cares (use the statement's Angle).
3. Walk them through the exercise ONE step at a time: give the exact action
   ("create file X containing…", "now run Y"), then STOP and wait. After each
   step, verify their work yourself — read the file, run the command — before
   moving on. Never batch steps; never do the learner's step for them.
4. Close with: the exam angle in one sentence, 2–3 oral comprehension
   questions (grade the answers), and any capability boxes from CURRICULUM.md
   Part A4 that can now be ticked.
5. Update PROGRESS.md: mark Taught with today's date and a one-line note.

If no argument was given, read PROGRESS.md and recommend the next untaught
statement, weighting toward Domain 1 (27%) and any flagged weak areas.
