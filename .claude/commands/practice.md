description: Independent practice for a CCAR-F task statement — examiner mode, verified feedback, no solutions
argument-hint: task statement id, e.g. 1.1, or "next"
---
Enter PRACTICE mode (see CLAUDE.md) for task statement: $ARGUMENTS

1. Read CURRICULUM.md for this statement's Independent exercise and its
   acceptance criteria (AC). Read PROGRESS.md.
2. Set the task: state the goal and the acceptance criteria ONLY. Do not give
   commands, file contents, or structure. You are an examiner now.
3. While the learner works: answer at most ONE hint per attempt, and only if
   they explicitly ask. A hint points at the area, never at the solution.
4. When the learner says "done": verify empirically against EVERY acceptance
   criterion — read the files, run the scripts, inspect real output. Do not
   accept descriptions of work you can check yourself.
5. Feedback: list criteria met, criteria missed, and for each miss name the
   trap pattern from CURRICULUM.md Part C it corresponds to.
6. Pass = all criteria met with no revealed solution. After two failed
   attempts you may show a solution — but then require a from-scratch redo in
   a fresh location before marking Practiced.
7. Update PROGRESS.md: Practiced status, pass/retry count, dated note.

If the argument is "next" or empty, pick the oldest statement that is Taught
but not yet Practiced.
